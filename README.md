# Feestje Halloween 2026

The spiritual successor to [feestje-10-23](https://github.com/DaXcess/feestje-10-23) (damn it's been three years already).

This is the source code for my outfit for Halloween 2026. It manages a set of LED-matrices, a StreamDeck, a Raspberry Pi (with camera) and multiple ESP32's. My plans for this year are much greater than last time I did this. First of all, I would like to drive the LED matrices (yes, I'm planning on using multiple this time) using ESP32's instead of directly through the Pi (which probably doesn't even have enough pins to drive both). I would also like to connect this version of the outfit to a website where people can control the matrix, and maybe even other parts of the outfit, from their phone by scanning a QR code.

What specific features I'm planning on adding is still TBD, but with more screen real-estate it is probably going to be a whole lot more animated than before.

This project is a WIP! Also it's my personal hobby project, probably not useful to anyone unless you like to read random people's source code.
